# Helenara Andrade — portfólio

Site estático publicado pelo GitHub Pages a partir da pasta `docs/`.

- `tools/build.py` gera o site a partir do acervo (apenas dados públicos: título, ano, técnica, materiais, dimensões, série e fotos).
- `data/base.json` contém as obras do catálogo 26 e as obras fora do catálogo.
- Preços, observações e localização das obras **não** fazem parte deste repositório.
